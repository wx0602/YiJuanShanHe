# 一卷山河

Windows 桌面应用，使用 C++17、Qt 6.5+、Qt Quick/QML、SQLite 和 CMake。当前完成山河首页、诗词典藏、诗人生平、诗人行旅、意象探索、诗词互动、个人空间和「诗心问墨」AI 助手。

## 运行

在 Qt Creator 中打开根目录的 `CMakeLists.txt`，选择 **Desktop Qt 6.5.3 MinGW 64-bit**（或兼容的 Qt 6.5+ Kit），构建并运行 `YiJuanShanHe`。

命令行构建需先将 CMake、Ninja、对应 Qt Kit 的 `bin` 和 MinGW 的 `bin` 加入 `PATH`：

```powershell
cmake -S . -B build/home -G Ninja -DCMAKE_PREFIX_PATH=D:/Qt/6.5.3/mingw_64
cmake --build build/home
./build/home/YiJuanShanHe.exe
ctest --test-dir build/home --output-on-failure
```

本机验证使用 Qt 6.5.3、MinGW 11.2.0、CMake 3.30。若使用 MSVC，请选择与 Qt 安装匹配的 MSVC Kit，并配置独立构建目录。

## 已实现

- 首页：水墨山峦、月色、云雾、诗词日历和功能入口；原有动效保留。
- 诗海拾珍：读取用户提供的 `shici.txt` 中全部 64 首诗词；支持标题/作者/正文搜索、朝代/作者筛选、排序、结果数量及每次 30 首的增量加载。
- 阅读：原文保留分行及序文；注释、译文、赏析由同一文件读取并分栏查看；支持沉浸阅读。
- 个人数据：收藏、笔记增改删及阅读历史写入 SQLite，重启后保留，并在个人空间集中查看。
- 数据错误、无搜索结果有明确提示。业务查询与写入在 C++ `PoemCatalog` 模型中完成，QML 负责界面和动效。
- 诗人生平：李白、杜甫、苏轼三人的独立档案；按姓名、朝代和称号搜索；分阶段浏览、按年代展开事件、点击来源链接，以及两位诗人的生卒年、人生阶段与重要事件并排对照。存疑年份和概括性阶段以「约」「≈」标注。
- 诗人行旅：李白、杜甫、苏轼的离线地图与有出处的行旅站点；支持鼠标拖动平移、滚轮及按钮缩放、地点悬停与点击、时间轴拖动、阶段切换、逐站播放、暂停、上一站、下一站、速度调整和复位视角。生平页右上角可将当前诗人带入行旅地图。
- 诗词互动：飞花令、诗词接龙、残卷修复三种玩法。飞花令由典藏原文生成电脑接句，用户接句按令字、加令和重复情况判定，不以本地典藏收录与否判错；支持倒计时与逐轮加令。残卷修复支持诗句排序、字词拼接、混入其他原文诗句三档。三种玩法均有 5/10/15 回合、提示、跳过、计分、回顾与学习记录。旧版填空和知识挑战成绩保留在历史记录中。
- 个人空间：使用现有收藏、笔记、阅读历史与答题记录展示真实概览。收藏可搜索、排序和取消；笔记可按诗人筛选、按时间排序、编辑和删除；阅读足迹可按本地日期筛选并在确认后清除。记录可跳回诗词典藏，学习区提供近七日趋势、分模式成绩、历史挑战和错题重练入口。昵称、题签头像、阅读字号、动效和双主题偏好在本机持久保存。
- 全局主题：默认「月白」暖金，可通过顶部日月按钮或个人空间切换「烟青」。主题覆盖已完成的全部页面；切换即时生效并保存，旧版「深青／夜墨」设置自动归入月白。颜色集中定义于 `qml/Theme.qml`，首页山水为两套主题分别绘制。
- 意象探索：读取独立意象词典，在本地诗词库中统计出现频次与共现关系，以离线星图和相关诗词列表呈现。
- 诗心问墨：自由问答、诗词鉴赏、本地诗词推荐与双诗对比；支持 Markdown、流式生成、取消、复制、重新生成和 SQLite 会话历史。典藏、生平、行旅、意象页可带当前资料跳转。Qt 客户端只请求独立后端；详细配置和部署见 [backend/README.md](backend/README.md)。

项目根目录的 [`shici.txt`](shici.txt) 是首页日历与「诗海拾珍」的共同文本来源。文件按 `01 标题｜朝代·作者`、正文、`【注释】`、`【译文】`、`【赏析】` 分段，共 64 首；未注明朝代的条目保留原署名，不补造元数据。首页日历按文件顺序取前 31 首对应每月的 1～31 日，默认选择系统本地日期。典藏展示全部 64 首与文件中的全部译注赏析。构建时会复制文本至可执行程序旁；运行时优先读取此文件，缺失时读取内置资源，也可用 `YIJUANSHANHE_SHICI_FILE` 指定路径。文件格式或条数不符时会显示错误，不会显示旧缓存内容。

典藏把 `shici.txt` 的解析结果同步到用户数据目录下独立的 `shici_archive.sqlite`，以便执行 SQLite 搜索并持久保存收藏、笔记与阅读历史；文本未变化时跳过重复同步。原有 `poetry.sqlite` 保留，旧诗词及其个人数据不删除，也不会混入新的 64 首典藏列表。新典藏的收藏和笔记保存在新数据库中，按文件条目编号关联。

诗词互动只读取该数据库的 `poems` 表，沿用 `interaction_attempts`、`interaction_rounds`、`interaction_mistakes` 表保存学习记录，不修改诗词正文。接龙只使用可明确切为上下半句的原文；若同一上句在库中对应多个下句，接龙会排除该句。残卷完成后展示典藏中的完整原文及已有赏析或注释；资料缺失时会明确提示。题库不足所选题数时会缩短本轮并提示。关闭程序后成绩与错题仍会保留。

个人空间复用 `favorites`、`notes`、`reading_history` 和互动记录表，只新增兼容的 `personal_settings(key,value)` 表。删除收藏、笔记、足迹前均会弹出确认。保存偏好后，阅读字号会影响典藏原文和首页日历正文，动效开关会影响页面切换、首页山水动态及典藏诗句渐显。全局「月白／烟青」主题与顶部切换按钮共用同一设置；旧版主题值仅迁移设置项，不更改诗词与学习记录。

AI 会话单独保存在 `ai_sessions` 和 `ai_messages`，不写入诗词原文表。默认客户端服务地址为 `http://127.0.0.1:8765`，须在本机启动后端才能得到真实模型回复；服务未连接不影响任何离线页面。正式部署时由开发者在构建或部署环节指定 HTTPS 服务地址。模型密钥只存在后端环境中，普通用户界面没有 API 配置项。

诗人生平资料保存在 [`data/poets.json`](data/poets.json)，由 C++ `PoetLifeModel` 读取、校验、排序与搜索。构建时会复制到可执行文件旁的 `data/poets.json`；运行时优先读取这份可编辑文件，缺失时读取内置资源。也可设置 `YIJUANSHANHE_POETS_FILE` 指向自选 JSON 文件，重启后生效。人物资料主要参考[故宫博物院：李白](https://www.dpm.org.cn/lemmas/240150.html)、[故宫博物院：杜甫](https://www.dpm.org.cn/lemmas/240158.html)、[故宫博物院：苏轼](https://www.dpm.org.cn/lemmas/242068.html)、[成都杜甫草堂博物馆](https://www.cddfct.cn/go-c11.htm)等；每个人物及事件在 JSON 中分别保存出处。

行旅站点保存在 [`data/journeys.json`](data/journeys.json)，与 `poets.json` 通过人物编号关联，均由 C++ `JourneyModel` 读取；可设置 `YIJUANSHANHE_JOURNEYS_FILE` 使用自选文件。构建时也会复制一份至可执行文件旁的 `data` 目录。地点坐标取现代城市或区域的**约略位置**，不指向古代建筑遗址。连线仅表达有文献支持的事件地点先后，**不是经考证的真实旅行道路**。年份及地点有争议时会在手札中标注，逐站出处见 JSON 的 `source` 字段。人物选择、时间线、播放状态和视野计算均由 C++ 管理。手札的关联诗词只对现有诗词数据库执行参数化只读查询，不修改诗词库。

离线地图素材 [`data/china-outline.svg`](data/china-outline.svg) 从 [Natural Earth 1:110m Admin 0 Countries](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson) 的简化矢量轮廓转换而来，并加入台湾岛的地理轮廓。[Natural Earth 使用条款](https://www.naturalearthdata.com/about/terms-of-use/)声明其地图数据为公共领域。此图只作为**现代地理定位底图**，不表达唐、宋时期疆域，也不适合边界或测绘用途；应用运行时不调用在线地图服务。

「山河行卷」按主题使用用户提供的 [`picture/xinglv1.png`](picture/xinglv1.png) 与 [`picture/xinglv2.png`](picture/xinglv2.png) 作艺术背景；两张完整 UI 参考图只用于设计参照。实际站点与路线依照经纬度投影，由独立的 [`data/china-outline-overlay.svg`](data/china-outline-overlay.svg) 辅助定位。背景中 AI 绘制的边界可能与地理数据不吻合，不能作为测绘依据。

行旅手札的「同时期诗笺」使用独立的 [`data/journey-readings.json`](data/journey-readings.json)：诗文从网上公开古籍核对后录入，并逐首保存原文链接、创作年代依据和站点关联说明。此处不查询本地诗词库，断网时仍可阅读；存疑年代明确标注，未核实的站点显示缺失提示。手札下方「本地典藏·诗中同名地点」则是另一个入口，仅按诗人与地名查找现有典藏作品，不作为同期诗作依据。

旧版典藏中的 16 首诗词仍保存在原数据库中；目前界面的 64 首原文与译注完全以用户提供的 `shici.txt` 为准，程序不会额外生成文本。

## 数据导入

旧版 `--import-poems <json文件>` 命令仍可写入原 `poetry.sqlite`，不会改变当前由 `shici.txt` 管理的「诗海拾珍」列表。扩展当前典藏应编辑 `shici.txt` 并重新构建或更新可执行程序旁的同名文件。

数据库位于 Qt 的用户数据目录。测试或便携运行可设置 `YIJUANSHANHE_DATA_DIR` 指向自选数据目录。
